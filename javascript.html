Interaction patterns

Use small, practical scripts to power dropdowns, search, theme switching, and smooth user feedback without bloated code.

Menu

Dropdown toggle

Toggle a navigation menu and close it when the user clicks outside the panel.

const menuButton = document.querySelector('.nav-toggle');
const menu = document.getElementById('menu');

menuButton.addEventListener('click', () => {
  menu.classList.toggle('show');
});
Theme

Theme switch

Persist user preference in local storage and apply it instantly on the next visit.

const savedTheme = localStorage.getItem('theme');
const root = document.body;

if (savedTheme) {
  root.classList.toggle('dark', savedTheme === 'dark');
}
Form

Validation message

Display clear validation feedback and keep the experience helpful and accessible.

const form = document.querySelector('form');
form.addEventListener('submit', (event) => {
  event.preventDefault();
  const input = form.querySelector('input');

  if (!input.value) {
    console.log('Please complete the field.');
  }
});
